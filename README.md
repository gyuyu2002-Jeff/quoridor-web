# 步步為營 · 迷宮對決

參考使用者提供的 [Facebook 遊戲影片](https://www.facebook.com/share/v/1ExydWuVpW/)，以標準 Quoridor 雙人規則製作的繁體中文網頁遊戲。保留 9×9 深色棋盤及藍、粉紅兩方。

## 使用

[直接開啟遊戲](https://gyuyu2002-jeff.github.io/quoridor-web/)

### 跟朋友線上對弈

1. 開啟遊戲，選「好友連線」→「建立房間，邀請朋友」。
2. 按「複製邀請連結」傳給朋友；朋友開啟連結後按「加入」。也可以直接輸入六碼房號。
3. 房主是藍方先手，朋友是粉紅方；棋局會自動同步。

線上模式需要網路，不需登入。重新整理同一個分頁可接回棋局，斷線時會自動重連。房間保留 24 小時；按「離開」會關閉房間。重新開局需要雙方同意，線上對戰不提供悔棋。

### 單人與同機雙人

從 [Releases](https://github.com/gyuyu2002-Jeff/quoridor-web/releases/latest) 下載 `index.html`，直接以瀏覽器開啟即可遊玩，無須伺服器、安裝套件或網路連線。預設為單人對電腦：你操作藍方，電腦操作粉紅方，也可切換為同機雙人。

若下載的是原始碼，請先依下方步驟執行 `npm run build`，再開啟產生的 `dist/index.html`。

- 藍方先手，每回合移動棋子或放一道牆。
- 電腦會自動尋路、選擇有利的障礙牆，並優先取勝或阻止對手立即獲勝；不需 API 金鑰或網路。
- 點亮點移動；放牆時選橫／直方向，再點縫隙預覽，最後確認。
- 棋盤旁有「確認放置」按鈕，手機版固定在畫面底部；先點選位置後即可確認，不用捲到操作區。
- 雙方各有 10 道牆，牆長兩格，不得重疊、交叉或封死任一方道路。
- 與對手相鄰且無牆時可直線跳過；後方被牆或邊界擋住時才可斜跳。
- 先到對面底線任一格獲勝。可悔一步、重新開始或查看完整規則。
- 單人模式的「悔一回合」會一起撤回你的行動及電腦的回應；電腦思考中也能悔棋或重新開始。切換對戰模式會重新開局。
- 支援鍵盤 Tab／Enter；放牆時方向鍵選位置、R 旋轉、Esc 清除預覽。

## 開發與驗證

使用 Node.js 22.13 以上，沒有外部依賴。

```text
npm test
npm run build
```

`src/game.js` 負責不可變遊戲狀態、移動與 BFS 通路檢查。`src/ai.js` 比較合法走子及放牆後的最短路程，選擇電腦行動。`src/app.js` 負責介面、回合排程與互動。建置只將 CSS 與 JavaScript 內嵌成單一 HTML；沒有追蹤、外部字型或圖片資源。

`src/network.js` 處理房間、每秒同步及斷線恢復。`worker/api.js` 是房間 API，由 Cloudflare Workers / Sites 與 D1 儲存棋局；伺服器驗證身分、回合與每一步規則，以版本條件更新避免重複操作。邀請連結只有房號，不包含玩家操作憑證。

`npm run build` 同時產生：

- `dist/index.html`：離線版，單人／同機雙人不需連線。
- `docs/index.html`：GitHub Pages 前端，使用 `main` 分支的 `/docs` 發布；修改後一併提交建置結果。
- `dist/server/index.js`：線上 API 與網頁的 Worker，配合 `.openai/hosting.json` 及 `drizzle/` 遷移發布至 Sites。

GitHub Pages 只提供前端。複製此專案到自己的帳號時，請部署自己的房間後端，並更新 `src/network.js` 的公開網址及 `worker/api.js` 的允許來源；不應共用其他人的後端。

影片未逐項解說細節，牆壁數量與跳躍細則採標準雙人規則。重新整理頁面會重設棋局。
